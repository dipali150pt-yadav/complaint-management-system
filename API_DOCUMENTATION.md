## Architecture Overview

### System Flow
```
Citizen Upload → Image Analysis → AI Classification → Database Storage → Admin Dashboard
      ↓              ↓                   ↓                    ↓              ↓
 index.html → ImageAnalysisService → AIService → ComplaintRepository → admin.html
```

### Service Architecture
```
HomeController
    ↓
ComplaintGenerationService
    ├── ImageAnalysisService (Computer Vision)
    │   ├── OpenAI GPT-4 Vision API
    │   ├── Google Cloud Vision API
    │   └── Local Rule-Based Analysis
    └── AIService (Categorization & Routing)
        ├── Category Detection
        ├── Department Assignment
        └── Priority Calculation
```

## Data Models

### Complaint Entity

```java
@Entity
public class Complaint {
    // Basic Information
    private Long id;                          // Auto-generated ID
    private String text;                      // Combined user + AI description
    private String status;                    // "Pending" or "Resolved"
    private String imagePath;                 // Path to uploaded image
    
    // AI-Generated Fields
    private String autoGeneratedDescription;  // AI's detailed description
    private String category;                  // Issue category (e.g., "ROADS & INFRASTRUCTURE")
    private String department;                // Assigned department
    private String severity;                  // "LOW", "MEDIUM", "HIGH", "CRITICAL"
    private Integer priority;                 // 1-5 (1 = highest)
    private Double aiConfidence;              // 0.0-1.0 (AI confidence score)
    private String detectedIssues;            // Comma-separated detected issues
    
    // Location Information
    private Double latitude;                  // GPS latitude
    private Double longitude;                 // GPS longitude
    private String address;                   // Street address
    private String landmark;                  // Nearby landmark
    
    // Citizen Information
    private String submittedBy;               // Citizen name or "Anonymous"
    private String contactNumber;             // Contact phone number
    
    // Timestamps
    private LocalDateTime submittedAt;        // Submission timestamp
    private LocalDateTime resolvedAt;         // Resolution timestamp
}
```

### Database Schema

```sql
CREATE TABLE complaint (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    text TEXT,
    status VARCHAR(50),
    image_path VARCHAR(500),
    
    auto_generated_description TEXT,

    department VARCHAR(200),
    severity VARCHAR(50),
    priority INT,
    ai_confidence DOUBLE,
    detected_issues TEXT,
    
    latitude DOUBLE,
    longitude DOUBLE,
    address VARCHAR(500),
    landmark VARCHAR(200),
    
    submitted_by VARCHAR(100),
    contact_number VARCHAR(15),
    
    submitted_at DATETIME,
    resolved_at DATETIME
);
```

## Service Layer APIs

### ImageAnalysisService

Provides computer vision analysis of uploaded images.

#### analyzeImage()

```java
/**
 * Analyzes image to detect civic issues
 * 
 * @param imageFile - Uploaded image file
 * @return ImageAnalysisResult with detected issues
 * @throws IOException if image processing fails
 */
public ImageAnalysisResult analyzeImage(File imageFile) throws IOException
```

**Returns**:
```java
class ImageAnalysisResult {
    String issueType;              // "Road Damage", "Sanitation Issue", etc.
    List<String> detectedIssues;   // ["Pothole", "Road surface damage"]
    String description;            // Detailed AI-generated description
    String severity;               // "LOW", "MEDIUM", "HIGH", "CRITICAL"
    Double confidence;             // 0.0-1.0
    String suggestedDepartment;    // "Roads & Infrastructure", etc.
    String recommendations;        // Suggested actions
}
```

**AI Provider Selection**:
- `openai`: Uses GPT-4o-mini vision model
- `google`: Uses Google Cloud Vision API
- `local`: Rule-based filename/keyword analysis

**Example Usage**:
```java
@Autowired
private ImageAnalysisService imageAnalysisService;

File image = new File("uploads/pothole.jpg");
ImageAnalysisResult result = imageAnalysisService.analyzeImage(image);

System.out.println("Issue: " + result.getIssueType());
System.out.println("Severity: " + result.getSeverity());
System.out.println("Confidence: " + result.getConfidence());
```

### ComplaintGenerationService

Orchestrates the complete complaint generation workflow.

#### generateComplaintFromImage()

```java
/**
 * Generates complete complaint from uploaded image
 * 
 * @param imageFile - Uploaded civic issue image
 * @param userText - Optional user description
 * @param latitude - GPS latitude (optional)
 * @param longitude - GPS longitude (optional)
 * @param address - Street address (optional)
 * @param landmark - Nearby landmark (optional)
 * @param submittedBy - Citizen name
 * @param contactNumber - Contact number (optional)
 * @return Fully populated Complaint object
 */
public Complaint generateComplaintFromImage(
    File imageFile,
    String userText,
    Double latitude,
    Double longitude,
    String address,
    String landmark,
    String submittedBy,
    String contactNumber
) throws IOException
```

**Workflow**:
1. Analyzes image with AI
2. Generates detailed description
3. Categorizes issue type
4. Assigns department
5. Calculates severity and priority
6. Adds location information
7. Timestamps submission

**Example**:
```java
File image = new File("uploads/garbage-issue.jpg");
Complaint complaint = complaintGenerationService.generateComplaintFromImage(
    image,
    "Overflowing garbage bin near my house",
    28.6139,    // latitude
    77.2090,    // longitude
    "123 Main Street, Sector 5",
    "Near City Mall",
    "Rajesh Kumar",
    "9876543210"
);
// Complaint is now ready to save to database
```

#### estimateResolutionTime()

```java
/**
 * Estimates resolution time based on severity
 * 
 * @param complaint - Complaint object
 * @return Human-readable time estimate
 */
public String estimateResolutionTime(Complaint complaint)
```

**Time Estimates**:
- CRITICAL: "24-48 hours"
- HIGH: "2-3 business days"
- MEDIUM: "3-7 business days"
- LOW: "7-14 business days"

## Web Endpoints

### Public Endpoints (No Authentication)

#### GET /
Redirects to login page.

#### GET /login
Display login form.

**Response**: `login.html` template

#### POST /login
Authenticate user.

**Parameters**:
- `username` (String): Username
- `password` (String): Password

**Response**: 
- Success: Redirect to `/admin` or `/home`
- Failure: Return to login with error

#### GET /home
Display citizen complaint submission form.

**Response**: `index.html` with modern UI

**Features**:
- Drag-and-drop image upload
- GPS location capture
- Optional contact information
- Real-time image preview

#### POST /submit
Submit new civic complaint with AI analysis.

**Parameters**:
- `image` (MultipartFile) [Required]: Issue photograph
- `complaint` (String) [Optional]: User description
- `latitude` (Double) [Optional]: GPS latitude
- `longitude` (Double) [Optional]: GPS longitude
- `address` (String) [Optional]: Street address
- `landmark` (String) [Optional]: Nearby landmark
- `name` (String) [Optional]: Citizen name
- `contact` (String) [Optional]: Phone number

**Response**: `success.html` with:
- Complaint ID
- AI analysis results
- Category and department
- Severity and priority
- Confidence score
- Estimated resolution time

**Example Request**:
```http
POST /submit HTTP/1.1
Content-Type: multipart/form-data

--boundary
Content-Disposition: form-data; name="image"; filename="pothole.jpg"
Content-Type: image/jpeg

[image binary data]
--boundary
Content-Disposition: form-data; name="address"

Main Road, Sector 15
--boundary
Content-Disposition: form-data; name="name"

John Doe
--boundary--
```

#### GET /track
Display complaint tracking form.

**Response**: `track.html`

#### POST /track
Track complaint by ID.

**Parameters**:
- `id` (Long): Complaint ID

**Response**: `track.html` with complaint details

### Admin Endpoints (Authentication Required)

#### GET /admin
Admin dashboard with comprehensive analytics.

**Response**: `admin.html` with:
- Total complaints count
- Pending complaints count
- Resolved complaints count
- High priority complaints count
- Average AI confidence
- Complaints table with all details
- Statistics by severity/department/category

**Data Model**:
```java
model.addAttribute("total", int);
model.addAttribute("pending", long);
model.addAttribute("resolved", long);
model.addAttribute("highPriority", long);
model.addAttribute("avgConfidence", String);  // e.g., "85%"
model.addAttribute("complaints", List<Complaint>);
model.addAttribute("bySeverity", Map<String, Long>);
model.addAttribute("byDepartment", Map<String, Long>);
model.addAttribute("byCategory", Map<String, Long>);
```

#### GET /resolve/{id}
Mark complaint as resolved.

**Parameters**:
- `id` (Long): Complaint ID

**Response**: Redirect to `/admin`

**Side Effects**:
- Sets `status` to "Resolved"
- Sets `resolvedAt` to current timestamp

#### GET /delete/{id}
Delete complaint permanently.

**Parameters**:
- `id` (Long): Complaint ID

**Response**: Redirect to `/admin`

**Warning**: This action is irreversible.

## AI Integration

### OpenAI GPT-4 Vision Integration

**API Endpoint**: `https://api.openai.com/v1/chat/completions`

**Request Format**:
```json
{
  "model": "gpt-4o-mini",
  "messages": [{
    "role": "user",
    "content": [
      {
        "type": "text",
        "text": "Analyze this civic issue image..."
      },
      {
        "type": "image_url",
        "image_url": {
          "url": "data:image/jpeg;base64,[base64_image]"
        }
      }
    ]
  }],
  "max_tokens": 500
}
```

**Response Format**:
```json
{
  "choices": [{
    "message": {
      "content": "{
        \"issueType\": \"Road Damage\",
        \"detectedIssues\": [\"Pothole\"],
        \"description\": \"...\",
        \"severity\": \"HIGH\",
        \"confidence\": 0.95,
        \"suggestedDepartment\": \"Roads & Infrastructure\"
      }"
    }
  }]
}
```

### Google Cloud Vision Integration

**API Endpoint**: `https://vision.googleapis.com/v1/images:annotate`

**Request Format**:
```json
{
  "requests": [{
    "image": {
      "content": "[base64_image]"
    },
    "features": [
      {"type": "LABEL_DETECTION", "maxResults": 10},
      {"type": "OBJECT_LOCALIZATION", "maxResults": 10}
    ]
  }]
}
```

**Response Processing**:
- Extract labels from `labelAnnotations`
- Map labels to civic issue categories
- Calculate confidence from label scores

### Local Analysis Integration

**Keyword Mapping**:
```java
Map<String, String> keywords = Map.of(
    "pothole|road|street", "Road Damage",
    "garbage|trash|waste", "Sanitation Issue",
    "light|lamp", "Street Lighting",
    "water|leak|drain", "Water Supply Issue"
);
```

**Confidence Calculation**:
- Filename match: 0.70-0.75
- No match: 0.60 (default)

```html
<!DOCTYPE html>
<html>
  <body>
    Complaint ID: 42
    Category: ROADS & INFRASTRUCTURE
    Department: Roads & Infrastructure
    Severity: HIGH
    Priority: 2
    AI Confidence: 95%
    Estimated Resolution: 2-3 business days
  </body>

```

### Error Handling

**Missing Image**:
```
Error: Please upload an image of the civic issue
```

**AI Processing Failure**:
- Falls back to text-based classification
- Still creates complaint with basic categorization
- Logs error for debugging

**Database Error**:
```
Error: Failed to save complaint. Please try again.
```
